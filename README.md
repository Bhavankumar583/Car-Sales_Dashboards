🚗 Car Sales Dashboard | Power BI Project
📊 Project Overview

This Power BI project focuses on analyzing car sales data to uncover key business insights such as revenue trends, pricing patterns, and customer behavior. The dashboard provides an interactive and visually appealing interface to monitor performance across different dimensions like time, region, and product categories.

🎯 Objectives
Analyze overall sales performance (YTD, MTD)
Identify trends in average car prices
Compare current vs previous year performance
Understand customer and regional distribution
Build an interactive dashboard for business decision-making
📈 Key Insights
💰 Total YTD Sales: 371M+
📊 Growth Rate: ~23.59% increase compared to previous year
🚘 Average Price Analysis shows variation across segments
📅 Strong monthly sales trends with peak performance periods identified
🌍 Regional and dealer-level performance highlights top contributors
🛠️ Tools & Technologies Used
Power BI Desktop
DAX (Data Analysis Expressions)
Data Modeling
Excel / CSV Dataset
📊 Dashboard Features
📌 KPI Cards (YTD Sales, MTD Sales, Avg Price, Growth %)
📅 Time-based analysis (Year, Month)
🌍 Region-wise and Dealer-wise insights
🎯 Dynamic filtering and slicers
📉 Comparative analysis (YTD vs PYTD)
🎨 Clean and modern dark-themed UI
